# 🏧 ATM Management System in Python

A simple console-based ATM Management System developed using Python. This project demonstrates the use of conditional statements, loops, functions, lists, and user authentication in a real-world banking scenario.

---

## 📌 Project Overview

The ATM Management System allows users to perform basic banking operations after successful PIN authentication. It simulates the functionality of an ATM and is suitable for beginners learning Python programming.

---

## ✨ Features

* 🔐 PIN Authentication
* 💰 Check Account Balance
* ➕ Deposit Money
* ➖ Withdraw Money
* 🔄 Change PIN
* 📄 View Mini Statement
* 🚪 Exit System

---

## 🛠️ Technologies Used

* Python 3
* Conditional Statements (`if`, `elif`, `else`)
* Functions
* Loops
* Lists
* User Input/Output
